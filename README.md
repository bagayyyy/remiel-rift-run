# 雷米埃尔 · 裂隙突围

手机拖动角色，电脑用左右方向键移动。游戏自动开火。每四波出现首领，击败它就进入下一轮。

## 惊鸿

每击碎一个补给箱获得 1 点储能，最多 3 点。点击「惊鸿」或按空格，消耗全部储能，立即一次结算所有伤害，并同时显示每段的粉色跳字。每点储能对应一段伤害和 0.8 秒时停。每段伤害按旧版单次伤害乘以储能点数再除以 3，四舍五入，满储能总伤害为旧版三倍。普通敌人时停 0.8、1.6 或 2.4 秒，首领最多停 1.5 秒且暂停发射新弹幕。已发出的弹幕继续飞行，角色在完整时停内无敌。

## 本地试玩

把压缩包完整解压，然后用浏览器打开 `index.html`。这款游戏不需要安装依赖。

## 发布到 GitHub Pages

1. 新建一个公开仓库，例如 `remiel-rift-run`。
2. 把解压出来的文件上传到仓库根目录并提交到 `main`，确保根目录能看到 `index.html`。
3. 在仓库的 **Settings → Pages** 中选择 **Deploy from a branch → main → / (root)**，点击 **Save**。
4. 部署成功后，在同一页面点击 **Visit site**。将打开的地址发给朋友即可。

角色卡使用参考图，图上署名保留。游戏运行在浏览器中，分数和最远波次保存在各自的浏览器。
