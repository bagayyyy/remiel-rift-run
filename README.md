# 雷米埃尔 · 裂隙突围

手机拖动角色，电脑用左右方向键移动。游戏自动开火。每四波出现首领，击败它就进入下一轮。

## 本地试玩

把压缩包完整解压，然后用浏览器打开 `index.html`。这款游戏不需要安装依赖。

## 发布到 GitHub Pages

1. 新建一个公开仓库，例如 `remiel-rift-run`。
2. 把解压出来的文件上传到仓库根目录并提交到 `main`，确保根目录能看到 `index.html`。
3. 在仓库的 **Settings → Pages** 中选择 **Deploy from a branch → main → / (root)**，点击 **Save**。
4. 部署成功后，在同一页面点击 **Visit site**。将打开的地址发给朋友即可。
